# State mission badge artwork prompts

The badge set was generated with the built-in image generation tool. Every badge used this shared direction:

> Create one polished circular enamel mission badge for the bright, playful Malaysia tourism game "Mystery Malaysia". Use a layered collectible-pin look, clean dimensional vector-like illustration, saturated tropical colours, a warm gold rim, strong silhouette, and a transparent or plain neutral exterior. Make the imagery original and tourism-focused. Do not use Malaysian or state flags, coats of arms, official seals, maps, copied logos, text, letters, numbers, or watermarks.
